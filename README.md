# Dev Experiments

Repositório para experimentos e aprendizado de funcionalidades que podem ser integradas em projetos futuramente.

---

## 🚀 Objetivo

Este repositório é um **laboratório de testes e aprendizado**. Aqui você encontrará scripts, provas de conceito e experimentos que podem ser úteis em projetos futuros, especialmente relacionados a:

- Extração de texto de PDFs
- Resumos automáticos de textos
- Adaptação de questões para alunos com TEA
- Testes de modelos de IA da Hugging Face
- Outras funcionalidades experimentais de desenvolvimento

--- 

## ⚠️ Observações

Este repositório é voltado para **experimentação e aprendizado**, então scripts e funcionalidades podem estar incompletos ou em desenvolvimento.
